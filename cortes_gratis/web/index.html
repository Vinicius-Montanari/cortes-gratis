              O botão deu erro? Outras formas de instalar
              
      
                
      1. Pela janela de comando (mostra cada passo e qualquer erro):
                  menu Iniciar → Instalar IA local. Ou, na pasta do programa:
                  "Cortes Gratis.exe" --instalar-ia-local
      
                
      2. Usando o Ollama oficial: instale pelo site
                  ollama.com/download,
                  rode ollama pull qwen2.5:7b e troque o endereço abaixo para
                  http://127.0.0.1:11434/v1. Nesse caso os modelos ficam onde o Ollama oficial guarda
                  (no C:, a não ser que você defina a variável OLLAMA_MODELS).
